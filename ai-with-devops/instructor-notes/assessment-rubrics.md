# Assessment rubrics

Per-lab rubric (10 points total)
- Functionality: 5 points — Does the solution meet the stated functional requirements?
- Safety & validation: 2 points — Are outputs validated and sensitive data protected?
- Tests & CI: 2 points — Are there automated tests or CI checks that validate behavior?
- Documentation & clarity: 1 point — Is the README clear and reproducible?

Capstone rubric (100 points scaled down as needed)
- Correctness & working demo: 40
- Integration across components: 20
- Security & safety features: 15
- Documentation & presentation: 15
- Bonus: extensibility, creative features: 10

Submission guidelines
- Submit via PR to the course repo or a shared classroom repo. Include instructions to run locally.

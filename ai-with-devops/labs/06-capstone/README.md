# Lab 06 — Capstone: Build an end-to-end AI-enhanced DevOps pipeline

Duration: 120 minutes (recommended)

Prerequisites: Completion of at least two prior labs

Goal: Create a small repo and CI pipeline that ties together changelog generation, test suggestions, and incident summarization.

Exercises
1. Sketch the pipeline flow and identify where human approvals are required.
2. Implement at least two LLM-assisted steps (e.g., changelog + incident summary) with guardrails and tests.
3. Prepare a 5-minute demo showing the pipeline in action.

Deliverable
- A demo repo or local run log, README with design decisions, and a short recorded demo or live presentation.

Files
- `starter/`, `solution/`, `tests/`, `demo_script.md`
